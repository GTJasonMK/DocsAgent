# 实施计划

## 基线

Base commit: unavailable（当前工作副本没有 `.git` 元数据；必须在真实 Git checkout 中记录完整哈希后提交计划包）

当前实现依据：`App` 集中编排聊天和设置；工具分发器路由项目、文档、网页、附件、命令和 MCP 能力；Agent Loop 有轮次、工具调用和上下文预算；会话与任务事件历史本地持久化，但活动执行循环不跨服务重启恢复。

## 实施任务

- TASK-001（REQ-001、REQ-010、REQ-011）：在现有有界 Agent Loop 上记录结构化进度事件，支持取消和明确的恢复错误；持久化会话与事件历史，不恢复跨重启中的执行循环。
- TASK-002（REQ-002、REQ-003、REQ-009）：按工具组声明模型 Schema，并在集中分发器执行范围/审批检查；增加当前工作区文件编辑、版本摘要冲突检测、项目检查命令执行、输出截断标记和密钥脱敏。
- TASK-003（REQ-004、REQ-005）：加入网页搜索/读取、隔离 Playwright 浏览器和 MCP 客户端；支持 `stdio`、Streamable HTTP、资源/提示模板/工具发现、服务器级配置和副作用审批。
- TASK-004（REQ-006、REQ-009）：增加 PDF、DOCX、XLSX、PPTX 文本提取和音轨转写；保留页码/工作表/幻灯片/时间戳定位，未接入视觉模型的输入显式失败。
- TASK-005（REQ-007）：完善项目检索和文档工作流；将来源证据、文档结构校验、代码文档事实校验与用户 Diff 审阅收敛到清晰接口。
- TASK-006（REQ-008、REQ-010）：增加本地会话/事件历史存储、可选长期记忆管理、附件生命周期管理、UI 进度和审批交互。
- TASK-007（REQ-001 至 REQ-011）：建立按任务类别划分的回归评测与威胁用例；按评测结果决定是否增加向量检索或并行子 Agent。

## 测试计划

- TEST-001 验证有界循环、错误重规划、取消与事件历史重启查询，覆盖 TASK-001、TASK-006。
- TEST-002 验证目录边界、基线冲突、编辑 Diff、配置命令与未授权命令、Git 提交确认，覆盖 TASK-002。
- TEST-003 验证网页/MCP 提示注入、MCP 传输、工具命名隔离、浏览器隔离和外部操作审批，覆盖 TASK-003。
- TEST-004 验证文本附件提取、音频依赖缺失、视觉能力缺失、来源定位和损坏/超限文件，覆盖 TASK-004。
- TEST-005 验证文档引用、需求编号映射、代码事实覆盖、校验结果和提案 Diff，覆盖 TASK-005。
- TEST-006 验证持久化隔离、记忆 opt-in、删除语义、事件顺序和前端审批流程，覆盖 TASK-006。
- TEST-007 使用标注任务报告完成率、证据有效性、文档质量、策略违规、延迟和成本；策略违规为发布阻断项，覆盖 TASK-007。

## 风险与回退

- 每个能力类别由独立开关控制；能力未配置或模型不支持时明确给出原因，不静默降级。
- 写入前验证文件基线；若任务期间文件被其他进程修改，停止写入并保留已收集证据。
- 命令和外部调用都有超时、输出/费用预算及取消处理；不重试不可重试错误，不自动重试有副作用的调用。
- 首发维持单 Agent；评测或本地沙箱能力不足时，禁用对应的执行能力，仍保留只读问答和文档提案。

## 交接

实现阶段按本计划拆分提交；每项实现同时添加或修订对应测试。每次提交前检查完整 Diff 和验证结果，提交由用户确认。后续计划从当前 HEAD 与前一提交 Diff 生成，并先审核计划文档再进入下一实现提交。
