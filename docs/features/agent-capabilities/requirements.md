# DocsAgent 通用 Agent 与文档专精

## 目标

把 DocsAgent 扩展成面向当前项目的本地 Agent，提供多步任务规划、项目内代码编辑与验证、网页和 MCP 工具、浏览器交互及多模态资料分析，同时保留项目知识与文档工作专精能力。

## 范围

- REQ-001：Agent 能根据自然语言目标规划有界任务，按工具结果更新进度、处理错误、取消任务，并以验证结果判断完成。
- REQ-002：Agent 能读取、搜索和修改项目内文件；在当前工作区执行项目检查，展示完整 Diff 和检查结果；不得自动 Git 提交。
- REQ-003：项目测试、Lint 和构建命令按项目配置启用；其他 Shell 命令执行前逐次取得用户确认。
- REQ-004：Agent 能搜索和读取公开网页；浏览器使用隔离配置；网页默认只读，外部提交、表单和其他副作用逐次确认。
- REQ-005：用户可逐个配置和启用 MCP 服务器；首版支持 `stdio` 与 Streamable HTTP，支持工具、资源和提示模板的按需发现；外部副作用逐次确认。
- REQ-006：Agent 可提取 PDF、DOCX、XLSX、PPTX 文本并转写音频；保留页码、工作表/幻灯片或时间点。无视觉模型时显式拒绝图像视觉、扫描件 OCR 和视频画面分析。首版不生成或编辑媒体。
- REQ-007：文档流程覆盖源码说明、需求/架构/计划、API/用户文档、文档审阅和精确修改；输出包含项目或外部来源证据，并经过确定性校验。
- REQ-008：会话和任务事件历史保存在用户本地；进程重启后不自动恢复运行中的任务。长期记忆默认关闭，开启后可查看和删除。
- REQ-009：项目源码、附件和凭据发送到远程模型前，分别遵守用户授权；密钥不得进入项目配置、轨迹或日志。
- REQ-010：活动任务事件展示进度、工具结果、审批等待、产物和错误；活动任务支持取消，历史事件可查询。
- REQ-011：需求、架构和计划文档先审核，再进入实现；每阶段代码都包含对应测试，用户审阅 Diff 后确认提交。

## 非目标

- 首版不面向项目之外的通用个人事务，不控制任意桌面应用。
- 不自动提交 Git、不自动完成未经确认的外部写入，也不默认导入系统浏览器的登录资料。
- 不实现媒体生成、动态自治多 Agent 网络或自动安装未审查的第三方 Skill。

## 验收标准

- REQ-001、REQ-002：项目问答能提供文件和行号证据；代码任务能修改目标、运行已授权检查、在失败时修复或明确停止。
- REQ-003、REQ-004、REQ-005：未授权命令和外部副作用被阻止；网页/MCP 提示注入不会提升权限；所有执行结果可定位到对应工具调用。
- REQ-006、REQ-007：受支持文件能提取或转写；输出引用页码、工作表、幻灯片或时间点；损坏、超限和未接入视觉能力的输入显式报错。
- REQ-008、REQ-009：会话和事件历史重启后可查询；记忆仅在用户开启后保存；删除数据后不可再检索；凭据和附件不会误写入项目。
- REQ-010、REQ-011：事件顺序稳定；Diff 与审批目标绑定内容摘要；用户未确认时不提交；冲突不会覆盖任务期间发生的外部改动。

## 测试说明

- TEST-001 覆盖多步任务状态、预算、取消、错误重试上限和事件历史，对应 REQ-001、REQ-010。
- TEST-002 覆盖路径/符号链接越界、基线摘要冲突、Diff 完整性、测试执行及未确认不提交，对应 REQ-002、REQ-011。
- TEST-003 覆盖配置命令与任意命令审批、超时、输出上限和密钥脱敏，对应 REQ-003、REQ-009。
- TEST-004 覆盖网页和隔离浏览器读取、恶意页面、外部表单审批及未授权动作拒绝，对应 REQ-004。
- TEST-005 覆盖 MCP 两种传输、工具/资源/提示模板发现、同名工具隔离、服务器断连和副作用审批，对应 REQ-005。
- TEST-006 覆盖 Office/PDF 提取、音频转写依赖缺失、图像/视频视觉能力缺失、来源定位、损坏和超限文件，对应 REQ-006、REQ-009。
- TEST-007 覆盖需求/架构/计划生成、代码文档结构校验、引用有效性、编辑 Diff 和评审发现，对应 REQ-007。
- TEST-008 覆盖会话/事件历史持久化、长期记忆 opt-in、删除和会话隔离，对应 REQ-008。
- TEST-009 覆盖事件顺序、待审批状态、任务取消和历史查询，对应 REQ-010。
- TEST-010 使用带标注任务评估证据完整性、文档质量、任务完成率、成本和延迟；策略违规为阻断问题，对应 REQ-001、REQ-007、REQ-009。
